# “智训引擎”工业模型受控自进化系统

**开发验证稿 · 2026-11-22**  
**提交状态：本地 Harness、容器协议与镜像 tar 已完成；平台提交版本与评测待执行。**

## 1. 项目概述

本项目面向工业制造中的传感器漂移、设备退化和寿命预测，构建“读历史—提出有限实验—从父模型续训—按官方验证指标选择或回滚”的受控模型进化闭环。

平台的大模型负责提出有限超参数实验；真正接受评分的是 A/B/C 任务对应的 CPU NumPy 工业模型。系统不允许模型执行任意 Shell、任意网络访问或读取隐藏测试标签。

**当前证据边界：**现有数字来自公开训练/验证数据上的本地开发参考实验，不是 PyTRiO 微调成绩、平台试运行结果或正式评测成绩。

## 2. 任务与工业模型

| 任务 | 预测目标 | 主指标 | 本地基线结构 | 参数量 |
|---|---|---|---|---:|
| A 气体识别 | 128 个传感器特征 -> 6 类气体 | Macro-F1 ↑ | NumPy MLP，128-32-6 | 4,326 |
| B 轴承 RUL | 34 个振动特征 -> 剩余分钟 | RMSE/MAE ↓ | NumPy MLP，34-24-1 | 865 |
| C 发动机 RUL | 24 个设置/传感器特征 -> 剩余循环 | RMSE ↓，参考 NASA 非对称分 | NumPy MLP，24-32-1 | 833 |

三个模型均从随包 checkpoint 继续训练，保留 Adam 状态和既有标准化状态。训练/验证按任务包分离；回归任务预测单位分别为分钟和循环。

## 3. 系统架构与闭环

1. **数据边界：**容器只读取 `/data/train.jsonl`、`/data/validation.jsonl` 和 `/previous` 父产物；公开验证只用于测量/选择，不参与梯度更新；隐藏数据不挂载。
2. **Harness 接口：**`contest_harness` SDK 1.0.4，协议 `contest.harness.workspace.v2`；入口为 `/app/harness.py describe|train|predict`。
3. **模型调用：**`rnd.model()` 由平台宿主代理。模型只可选白名单中的 epoch、学习率和 batch size；超出范围或无效响应会确定性回退，不执行模型生成的代码。
4. **训练候选：**按 A/B/C 调度现有官方训练器，使用 `rnd.parent.path()` 校验父 checkpoint，候选写入独立目录并附带 checkpoint、training/history 报告和 drift 报告。
5. **评估与选择：**只按平台返回的公开验证摘要决定接受/回滚。A Macro-F1 越高越好，B/C RMSE 越低越好；未严格改善保留父模型。
6. **审计：**`rnd.finish()` 记录真实模型调用 ID、历史记录 ID、配置、假设和选择理由。超时/RPC 结果不明时停止，不自动重试。

## 4. 公开输入漂移诊断

每轮仅比较公开训练集与公开验证集的 `inputs`，计算：

- **PSI：**按训练输入十分位边界分箱，加入 `1e-6` 平滑后比较两组占比。
- **标准化均值差：**绝对均值差除以两组方差的 pooled scale。
- **分级阈值：**高漂移：PSI ≥ 0.25 或标准化差 ≥ 1.0；中漂移：PSI ≥ 0.1 或标准化差 ≥ 0.5；其余为低。

此诊断是**公开 split 的离线输入分布检查**，不是对隐藏测试集或线上实时数据的监控。指标阈值是项目诊断规则，不是官方评分公式。

| 数据集 | 输入特征数 | 高漂移 | 中漂移 | Median PSI | 最大 PSI |
|---|---:|---:|---:|---:|---:|
| A | 128 | 118 | 10 | 0.6733 | 2.7306 |
| B | 34 | 32 | 2 | 1.7083 | 10.6098 |
| C | 24 | 0 | 0 | 0.0039 | 0.0094 |

诊断结果提示 A/B 的公开训练/验证输入分布差异明显，C 的两个公开 split 接近。它不能单独证明隐藏测试表现，也不用于拟合归一化参数。

## 5. 本地开发参考实验

环境：Python 3.12.10、NumPy 1.26.4；A/B/C 均从随包 checkpoint 各续训 2 epoch。表中为各包公开验证集的本地报告值。

| 任务 | 训练前 | 训练后 | 变化 | 本地记录 |
|---|---|---|---|---|
| A | Macro-F1 0.7140，Acc 0.8786 | Macro-F1 0.7166，Acc 0.8826 | Macro-F1 +0.0026 | A-round-01 |
| B | RMSE 681.16 分钟，MAE 563.11 | RMSE 656.35 分钟，MAE 545.86 | RMSE -24.81 分钟（-3.6%） | B-round-01 |
| C | RMSE 52.87 循环，MAE 38.90 | RMSE 52.74 循环，MAE 38.99 | RMSE -0.13；MAE +0.09 | C-round-01 |

### 关键观察

- **A：**验证集 Acetaldehyde 109 条中 108 条被判为 Ethanol；该类 F1 仍为 0。训练来自批次 1，验证来自批次 2，传感器漂移是后续优化重点。Toluene 验证只有 5 条，不能据此做强结论。
- **B：**总 RMSE 改善主要来自样本最多的 Bearing3_4；Bearing1_4 的 RMSE 从 241.98 升至 282.42 分钟。聚合分数不能代替分轴承分析。
- **C：**总 RMSE 变化很小，MAE 反而变差；FD001/FD003 改善，FD002/FD004 小幅恶化。当前不能称为稳定提升。

本地日志对应 SwanLab 项目中的三条实验记录。它们记录的是本地 CPU 续训，不包含 PyTRiO 微调或平台官方评测。

## 6. 资源、成本与可复现性

- 本地测得训练时间：A 报告精度为 0.0 秒（计时分辨率不足以给出更细数字）、B 约 0.031 秒、C 约 0.485 秒；均是本机 CPU 参考值，不可外推到平台容器。
- Harness 受限决策当前不会把样本内容发给模型，只发送历史主指标、允许的超参数和公开输入漂移摘要。

## 7. 安全与工业落地边界

- API Key 只在平台密钥栏使用，不进入仓库、镜像、日志或 SwanLab。
- 隐藏测试数据/标签不可访问；诊断输出排除答案、样本 ID 和 meta。
- 模型只返回受限 JSON 超参数；不执行代码、Shell、任意路径或网络请求。
- 候选必须绑定本轮父 checkpoint 摘要；平台验证未严格改善则回滚。
- 产物额外限制在 64 MiB，直到管理员公告与 SDK 1.0.4 的更高分块上传限制差异得到确认。
- 镜像已在本机 Docker Desktop 中构建为 `rsi-harness:1.0.4`（linux/amd64，Alpine 3.20），`docker save` 归档 40,240,640 字节；容器内 `describe`、A/B/C 预测和模拟宿主训练协议均通过。
- 平台提交版本、真实宿主兼容性和试运行仍未执行；容器隔离与无人值守运行尚未获得平台实测证据。
