受控进化：让模型提议，不让它越权

首版把模型动作限制为可验证的超参数选择。

输入

最小上下文

任务合同、最多 10 条历史主指标、白名单配置。

不发送原始样本、答案、ID、meta 或历史自由文本。

动作

严格 JSON

epochs / learning_rate / batch_size。

不接受代码、Shell、路径或额外字段；无效响应固定回退。

验证

平台指标

A Macro-F1 越高越好；B/C RMSE 越低越好。

候选摘要无效或未严格改善时回滚。

安全边界

  • 父 checkpoint SHA-256 必须由 SDK 校验。
  • 候选写到独立 /workspace，产物上限保守按 64 MiB。
  • API Key 只进平台密钥栏，不进镜像或源码。
  • RPC 状态不明时停轮，不自动重试。
